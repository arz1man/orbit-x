# Orbit-X | Aerospace Tourism

An immersive, high-tech landing page for a company that offers futuristic commercial space tourism and suborbital flights. 

Built during the ReVibe Symposium Mini-Hackathon!

## Tech Stack
- HTML5
- Tailwind CSS (via CDN for speed)
- Anime.js (for smooth, cinematic animations)
- Fontshare (Clash Display & Satoshi)

## Features
- Fully responsive design
- Cinematic entrance animations
- Scroll-triggered reveal animations
- Premium typography and styling

## How to run locally
Simply open `index.html` in your browser!

```bash
# If you have python installed, you can run a local server
python -m http.server 8000
# Then visit http://localhost:8000
```
